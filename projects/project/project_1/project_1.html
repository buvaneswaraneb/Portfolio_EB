01 — VS Code Extension

AI Vulnerability
Checker

A VS Code extension powered by DeepSeek and Hugging Face's OpenAI router API. Scans your code for security vulnerabilities in real-time, highlights exact lines, reports severity levels, and recommends fixes — all inside a sleek interactive webview.

JavaScript TypeScript Python VS Code API Hugging Face DeepSeek CyberSecurity
↗ View on GitHub View Screenshots

Features

What it does

Real-time Scanning

Scan any open file on demand with a single command. No build step required.

Exact Line Highlighting

Pinpoints the exact vulnerable line and code snippet in your file.

Severity Levels

Issues are classified as CRITICAL, HIGH, MEDIUM, or LOW for clear prioritisation.

Actionable Fixes

Each vulnerability includes a concrete, developer-ready recommendation.

Interactive Webview

Results appear in a rich, color-coded webview panel right inside VS Code.

Secure Key Storage

Your Hugging Face API key is stored securely in VS Code's global state.

Severity Scale

How issues are rated

Every detected vulnerability is assigned one of four severity levels so you can triage and fix the most dangerous issues first.

Critical
High
Medium
Low

Example Output

What a report looks like

Results are displayed in a visually rich webview with color-coded badges, vulnerable snippets, and recommended fixes.

[VULN-001] | CRITICAL | Line 12 Vulnerable Code: const password = "12345"; Issue: Hardcoded password detected. Fix: Use environment variables or a secure vault. [VULN-002] | HIGH | Line 45 Vulnerable Code: eval(userInput); Issue: Unsanitized user input passed to eval(). Fix: Avoid eval() or sanitise input before execution.

Installation

Getting started

1
Download the .vsix file
Grab the latest release from the GitHub releases page.
2
Install via Extensions panel
Open VS Code → Extensions → Click ··· → Install from VSIX → Select the file.
3
Or install via terminal
Run the command below in your terminal:
code --install-extension ai-vulnerability-check-0.0.1.vsix
4
Reload VS Code
Restart VS Code to activate the extension. You're ready to scan.

Usage

Running a scan

1
Open any code file
The extension supports JavaScript, Python, Java, C/C++, Go, and more.
2
Open the Command Palette
Press Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (macOS).
3
Run "Scan Code for Vulnerabilities"
Type and select the command. Enter your Hugging Face API key if prompted.
4
Review the report
A side webview opens showing vulnerability count, severity breakdown, snippets, and fixes.

Supported languages
